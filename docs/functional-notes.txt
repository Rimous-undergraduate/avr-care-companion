평상시(접근, 움직임 감지, 복약 관련 플래그 Clear 상태; IDLE)
-> 🙂 표정 on CLCD

근접해 있으면(근접 상태면) by 초음파 센서
-> 😆 표정 on CLCD
-> 꼬리 살랑살랑 on 서보모터
-> 움직임 감시 카운터 초기화 on MCU
-> '움직임 완료' 전송 on UART

멀어지면(근접 상태에서 평상시 상태로 바뀌면; 근접 FLAG Clear되면)  by 초음파 센서
-> 🥺 표정 on CLCD(3초간 유지)	// 우선순위 오버레이 LOW
-> 꼬리 멈춤 on 서보 모터

움직임 감시 카운터 n시간 초과하면 by MCU 카운터
-> '움직임 미 감지 시간: n시간' 전송 on UART
-> 무표정 on CLCD

움직임 감시 카운터 m시간 초과하면 by MCU 카운터
-> '움직임 미 감지 시간: m시간' 전송 on UART
-> 약간 슬픈 표정 on CLCD

움직임 감시 카운터 초과하면 by MCU 카운터
-> '문제 발생' 전송 on UART
-> 슬픈 표정 on CLCD

--------------------------------------------

약 먹을 시간 되면 by MCU 카운터
-> '약 복용 시간' 전송 on UART
-> 알람 소리 재생 on 피에조 부저
-> 눈 커진 표정 on CLCD

복약 확인 버튼 누르면 by 버튼 스위치
-> '약 복용 완료' 전송 on UART
-> 알람 소리 멈춤 on 피에조 부저
-> 😆 표정 on CLCD(3초간 유지)	// 멀어지는 얼굴보다 우선 -> 우선순위 1번(최우선) ; 우선순위 오버레이 MID
-> 복약 카운터 초기화 on MCU => 카운터가 아니라 특정 시간에 먹는 걸로 수정함. 고로 초기화 X

+ 약 먹을 시간 전에 복약 확인 버튼 누르면 by 버튼 스위치
-> '적정 시간보다 00시간 빨리 약 복용' 전송 on UART
-> 놀란 표정 on CLCD(3초간 유지; '접근'보다 우선해서 수행) // 우선순위 1번(최우선) ; 우선순위 오버레이 MID
-> 복약 카운터 초기화 on MCU => 위 수정 사항 참고.
